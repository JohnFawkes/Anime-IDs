This is an autogenerated list for mapping AniDB IDs to MyAnimeList IDs, AniList IDs, TVDb IDs, and IMDb IDs for use with [Kometa](https://github.com/Kometa-Team/Kometa).

This list is generated daily at 12:00 AM UTC 

## Format

This is an example mapping entry you would find in the [anime_ids.json](https://raw.githubusercontent.com/Kometa-Team/Anime-IDs/master/anime_ids.json) file.

```json
{
  "11": {
    "tvdb_id": 70900,
    "imdb_id": "tt7941838",
    "mal_id": 821,
    "anilist_id": 821,
    "tmdb_movie_id": 327796,
    "tmdb_show_id": 12121
  }
}
```

- The main key of each entry is the AniDB ID of the entry. 
- `tvdb_id`: This is always the Series ID that contains the show/season/movie/special. **This should never be a TVDb Movie ID or TVDb Season ID.**
- `imdb_id`: This should be the IMDb ID of the Series for shows and seasons, but should link directly to the IMDb ID of the Movie or Special if it is one. You can provide multiple comma-separated IMDb IDs if the Anime is a series of Movies/Specials.
- `mal_id`: This should link directly to the exact same anime on [MyAnimeList.net](https://myanimelist.net). You can provide multiple comma-separated MyAnimeList IDs if the Anime has multiple entries.
- `anilist_id`: This should link directly to the exact same anime on [AniList.co](https://anilist.co). You can provide multiple comma-separated MyAnimeList IDs if the Anime has multiple entries.
- `tmdb_movie_id`: This is the TMDb ID of the Movie AnimeMap matched to the anime.
- `tmdb_show_id`: This is the TMDb ID of the Series AnimeMap matched to the anime.

## Source Lists

`anime_ids.json` is autogenerated from a single source.
1. [AnimeMap](https://mapping.animemap.dev) maps AniList IDs to AniDB IDs, MyAnimeList IDs, TVDb IDs, TMDb IDs, and IMDb IDs. ([Raw List](https://mapping.animemap.dev/api/v1/export.json))

AnimeMap is keyed on AniList ID while `anime_ids.json` is keyed on AniDB ID, so only AnimeMap entries that carry an AniDB ID end up in this list. Where several AniList entries share one AniDB ID their IDs are combined into a comma-separated value.

## Make Changes

To change ID's mapped in the autogenerated `anime_ids.json` report the incorrect or missing mapping to [AnimeMap](https://mapping.animemap.dev), which is where every ID in this list comes from.

If that doesn't work you can also submit a Pull Request to the Repo editing the `anime_id_edits.json` file. The format of each entry is defined above. You should only edit the IDs you actually want changed.

```json
{
  "9826": {
    "mal_id": "18397,25781,36106"
  },
  "10583": {
    "mal_id": "23775,23777"
  }
}
```

## Common Kometa Convert Erorrs

If any **Solution** doesn't work you can always manually make changes using the `anime_id_edits.json` file.

- `No TVDb ID or IMDb ID found for AniDB ID: #####`
  - **Issue:** [AnimeMap](https://mapping.animemap.dev/api/v1/export.json) has no TVDb ID or IMDb ID matched against the AniList entry that AniDB ID belongs to.
  - **Solution:** Report the missing mapping to [AnimeMap](https://mapping.animemap.dev).

- `AniDB ID not found for MyAnimeList ID: #####`
  - **Issue:** Kometa received a MyAnimeList ID from a Builder and no AniDB ID is mapped to that MyAnimeList ID on [AnimeMap](https://mapping.animemap.dev/api/v1/export.json).
  - **Solution:** Report the missing mapping to [AnimeMap](https://mapping.animemap.dev). Note that an AnimeMap entry only reaches this list if it has an AniDB ID matched to it, so a MyAnimeList ID with no AniDB match won't appear here.

- `AniDB ID not found for AniList ID: #####`
  - **Issue:** Kometa received an AniList ID from a Builder and that AniList entry has no AniDB ID matched to it on [AnimeMap](https://mapping.animemap.dev/api/v1/export.json).
  - **Solution:** Report the missing mapping to [AnimeMap](https://mapping.animemap.dev).

- `AniDB ID: {anidb_id} not found`
  - **Issue:** Kometa is looking at an AniDB ID that no [AnimeMap](https://mapping.animemap.dev/api/v1/export.json) entry is matched to.
  - **Solution:** Either the AniDB ID is wrong — a Builder sending bad data or a guid tag in Plex with a non-numeric character — or AnimeMap has no entry matched to it yet, in which case report it to [AnimeMap](https://mapping.animemap.dev).

- `AniDB ID not found for IMDb ID: #####`
  - **Issue:** Kometa received an IMDb ID from a Builder and that IMDb ID is not matched to any entry with an AniDB ID on [AnimeMap](https://mapping.animemap.dev/api/v1/export.json).
  - **Solution:** Report the missing mapping to [AnimeMap](https://mapping.animemap.dev).

- `AniDB ID not found for TVDb ID: #####`
  - **Issue:** Kometa received a TVDb ID from a Builder and that TVDb ID is not matched to any entry with an AniDB ID on [AnimeMap](https://mapping.animemap.dev/api/v1/export.json).
  - **Solution:** Report the missing mapping to [AnimeMap](https://mapping.animemap.dev).
